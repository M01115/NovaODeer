How the rig works

  • One character, many states, switched by name. Duolingo runs Duo the same way.
  • Parts move on their own: whole body, squash, puff, fin, tail, beret, brush, glasses, each eye's lids and pupil, mouth.
  • Mouths swap between 9 shapes. Effects (tears, sweat, Zzz, steam) are separate pieces shown per state.

Building it in Expo

  • Draw each part with react-native-svg (the same PNG layers, same positions).
  • Animate with Reanimated: copy the timings and moves from each card. Both run in Expo Go.
  • Pupils and lids are clipped to the eye shape with an SVG mask, like here.

What changed from the drawing

  • The mouth was painted into the body layer. I removed it so mouths can change.
  • Each eye is now separate, with the pupil removed so it can move and shrink.
  • Nothing else was redrawn.
